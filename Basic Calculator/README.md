## 目录约定

每个项目在仓库根目录下拥有独立的文件夹，彼此互不干扰：

```
mycode/
├── README.md          # 本文件：项目索引与使用说明
├── .gitignore         # 通用忽略规则
├── project-a/         # 项目 A 的全部文件
│   ├── README.md      # 项目自身的说明文档
│   └── ...
└── project-b/
    ├── README.md
    └── ...
```

## 新增一个项目

1. 把项目文件夹放到仓库根目录（也可以直接 `git clone` 到该目录）
2. 在项目文件夹里补一个简短的 `README.md`，说明用途、运行方式
3. 在上面的「项目索引」表格中加一行
4. 提交并推送：

```bash
git add .
git commit -m "feat(<项目名>): 添加新项目"
git push
```

## 公开仓库注意事项

本仓库是 **公开** 的，任何人都能查看全部文件与提交历史，因此：

- 不要提交密码、API Key、Token、私钥等敏感信息
- 不要提交包含个人隐私的数据文件
- 敏感信息一旦提交，即使后来删除仍保留在历史记录中，需要重写历史才能彻底清除
- 提交前可以用 `git status` 和 `git diff --staged` 检查一遍将要推送的内容

`.gitignore` 已默认忽略常见的敏感文件、依赖目录和构建产物。
